# Setup do Supabase

1. Crie um projeto no Supabase.
2. Rode o arquivo [`supabase-schema.sql`](./supabase-schema.sql) no SQL editor.
3. Copie `SUPABASE_URL` e `SUPABASE_ANON_KEY` para o ambiente local.
4. Execute `npm start`.
5. Abra `http://localhost:3020`.

## Tabelas

- `environments`
- `curl_history`

## Observacao

O catalogo de endpoints e fixo no codigo. Voce cadastra ambientes e o historico dos testes fica em `curl_history`.
